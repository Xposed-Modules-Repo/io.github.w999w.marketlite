# 商店轻享 · MarketLite

小米应用商店界面自定义模块，支持广告和推荐展示调整、首页标签管理、底栏与个人页快捷入口。仅作用于小米应用商店，不修改安装验证、设备标识或安全检查。

实机测试：Xiaomi 14 Pro / HyperOS 3 / Android 16 / Vector。其他机型和版本尚未全面验证。
